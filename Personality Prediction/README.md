## 🧠 Project Overview

The **Personality Predictor** is a web-based application built using **Streamlit** and **LightGBM**, designed to predict whether a person is an **Extrovert** or **Introvert** based on behavioral features such as:

- Time spent alone  
- Stage fear  
- Social event attendance  
- Going outside  
- Drained after socializing  
- Friends circle size  
- Post frequency  

The model is trained using a Kaggle dataset (Playground Series S5E7) and provides a **real-time, interactive prediction interface**.

---

## ⚙️ Features

- Input features through **select boxes**  
- Predict personality type on **button click**  
- Shows a **simple, user-friendly result**: "You are an Extrovert/Introvert person"  
- Built using a **LightGBM pipeline** including preprocessing
